# AI-Generated-Text-Detector

The **AI-Generated-Text-Detector** is a project aimed at distinguishing between AI-generated text and human-written text. This repository contains code and models designed to achieve this detection with high accuracy.

## Dataset

The dataset used for training the models can be found on Kaggle:  
[AI-Generated vs Human Text (95% Accuracy)](https://www.kaggle.com/code/syedali110/ai-generated-vs-human-text-95-accuracy/input)

## Features

- Detects AI-generated text with high accuracy.
- Provides tools for preprocessing and analyzing textual data.
- Built using Jupyter Notebook for an interactive development experience.

## Requirements

To use this repository, ensure you have the following installed:

- Python 3.8 or higher
- Jupyter Notebook
- Required Python libraries (listed in `requirements.txt` if applicable)

## Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/ChapelFob80930/AI-Generated-Text-Detector.git
   ```

2. Navigate to the project directory:
   ```bash
   cd AI-Generated-Text-Detector
   ```

3. Install the dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

1. Open the Jupyter Notebook:
   ```bash
   jupyter notebook
   ```

2. Run the notebooks to train the models or test the detection capabilities.
